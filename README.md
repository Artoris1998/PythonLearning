### Day 04｜2026/11/02
-**今天學到：**
-比較運算子與條件判斷（if、elif、else）
  -'>'大於、'<'小於、'>='大於或等於、'<='小於或等於、'=='等於、'!='不等於
-條件判斷:
  -'if'：當條件成立時執行。
  -'elif'：當前面的條件不成立時，繼續檢查其他條件。
  -'else'：當前面的條件都不成立時執行。
-理解條件成立與不成立時，程式執行流程的差異。
-認識 Python 縮排的重要性。
-**注意事項**
  -'=' 是指定變數的值。
  -'==' 才是比較兩個值是否相等。
  -條件判斷內部需要正確縮排。
  -從 Day 05 開始，統一使用四個空格縮排
